# Watchmark frontend

React + TypeScript + Vite single-page app. See the repository root `README.md`
for setup; common commands:

```sh
npm run dev        # http://localhost:5173, proxies /api and /actuator to :8080
npm test           # Vitest + React Testing Library
npm run lint       # oxlint
npm run typecheck  # tsc project build, no emit
npm run build      # production bundle in dist/
```
